# Kevmodrome App Store

Community apps for [umbrelOS](https://umbrel.com), maintained by [kevmodrome](https://github.com/kevmodrome).

## Add this store to Umbrel

1. Open the App Store on your Umbrel.
2. Open the **⋯** menu and choose **Community App Stores**.
3. Paste this repository URL and click **Add**:

   ```text
   https://github.com/kevmodrome/umbrel-community-app-store
   ```

4. Open the **Kevmodrome** store to browse its apps.

## Apps

| App | Version | Client connection |
| --- | --- | --- |
| [Jean](docs/jean.md) | 1.0.13 | Headless server for the Jean desktop app |
| [Paseo](docs/paseo.md) | 0.14.0 | Headless server for Paseo desktop and mobile apps; Codex and Claude Code included |
| [Happier](docs/happier.md) | stable-a2c45c86804b | Private relay and coding runner for Happier desktop and mobile apps |
| [Open Session](docs/opensession.md) | 0.4.79 | Browser workspace protected by Umbrel login; Codex and Claude Code included |

Jean, Paseo and Happier connect to native clients using your Umbrel's hostname or IP address and the app's connection port. Use the password generated by Umbrel as Jean's remote-server token or Paseo's daemon password. Happier uses its own encrypted account and machine-pairing flow instead of an app password; follow its setup guide before connecting the runner. Open Session opens a browser workspace through Umbrel's authenticated app proxy.

Each app needs your own coding-provider account or API key and keeps separate credentials. For Jean, Paseo and Happier, sign in on the remote machine through the client's terminal or sign-in flow. To use a Codex subscription there, run `codex login --device-auth` and complete ChatGPT sign-in from the displayed link; `codex login status` confirms the authentication method. Open Session supports ChatGPT device-code sign-in under **Workspace → Providers** in the browser. Its Claude setup requires a token generated with `claude setup-token` on a trusted machine; see [its setup guide](docs/opensession.md). Logging in on your laptop does not log in an app's remote container. See [OpenAI's headless authentication documentation](https://learn.chatgpt.com/docs/auth).

Repositories, settings and provider credentials persist across app restarts and updates. Each app has its own home directory and an optional **Projects** folder setting. Agents run inside the app containers on your Umbrel.

The packages support AMD64 and ARM64. Their connection ports are **13456** for Jean, **16767** for Paseo, and **13005** for Happier; Open Session's browser endpoint uses **13850**. See each app's setup guide for connection and sign-in instructions.

## Add an app package

The store ID is `kevmodrome`. Every app directory and its manifest `id` must use the `kevmodrome-` prefix, for example `kevmodrome-jean`, `kevmodrome-paseo` or `kevmodrome-happier`. Keep these IDs stable after publishing.

Each app lives in a top-level directory containing its listing and container configuration:

```text
umbrel-app-store.yml
kevmodrome-<app-name>/
  umbrel-app.yml
  docker-compose.yml
  data/                 # Persistent app state, when needed
```

Use prebuilt, publicly pullable images pinned to tested versions and image digests. Persist app state under `${APP_DATA_DIR}/data`, and verify installation, client authentication, agent setup, and persistence across restarts and updates before publishing a package.

See [Umbrel's current packaging guidance](https://github.com/getumbrel/umbrel-apps/blob/master/.agents/skills/umbrel-package-app/SKILL.md) for the app manifest and runtime requirements.

The validation workflow checks packages against Umbrel's official app port catalogue and tests server startup and persistence, plus app-specific authentication and pairing. These smoke checks do not sign into real coding-provider accounts. Image workflows build both supported architectures from [`images/jean/Dockerfile`](images/jean/Dockerfile), [`images/paseo/Dockerfile`](images/paseo/Dockerfile), [`images/happier/Dockerfile`](images/happier/Dockerfile) and [`images/opensession/Dockerfile`](images/opensession/Dockerfile); image updates require updating the package's pinned digest after a successful build.

This store was created from [Umbrel's Community App Store template](https://github.com/getumbrel/umbrel-community-app-store).
